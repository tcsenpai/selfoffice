# מודלים של AI והגדרות

## ספקים ומודלים

מודלים ומפתחות מוגדרים בהגדרות (שורת החשבון בפינה השמאלית-תחתונה של הבית):

![חלון ההגדרות](img/settings-general.png)

- **Claude (מנוי)** (ברירת מחדל): משתמש בהתחברות ה-CLI המקומית של `claude` — מריצים `claude login` פעם אחת; מודלים sonnet, opus, haiku; טקסט בלבד, בלי תמונות. **Codex CLI** נתמך גם הוא, ושרתים מקומיים כמו Ollama או LM Studio פועלים כנקודות קצה מותאמות תואמות OpenAI.
- **חיפוש ברשת ומדיה**: חיפוש ברשת עובד בלי מפתח (שרשרת חינמית; ספקים עם מפתח הם אופציונליים). יצירת תמונות וניתוח מדיה נשארים כבויים עד שמוגדר ספק AI Media.
- **נקודות קצה מותאמות (BYOK)**: הגדרות ▸ AI לוקחות Base URL ומפתח API לכל פרוטוקול — OpenAI תואם, Anthropic, Gemini, DeepSeek, DashScope (qwen) ועוד. המפתחות נשמרים בקובץ ההגדרות של האפליקציה במחשב הזה ונשלחים רק בכותרות הבקשה. Atlas Cloud בין הפרוטוקולים המובנים.
- אפשר לבחור מודל אחר לכל יכולת: צ׳אט/יצירה, יצירת תמונות, ניתוח תמונות.
- **בדיקת חיבור**: אימות שהנקודה נגישה ושהמודלים גלויים לפני השמירה.
- ל- Base URL יכול להיות גם נתיב ומחרוזת שאילת (בסגנון gateway); נתיבי נקודות הקצה מתווספים בצורה נכונה.

## אינטגרציית CLI (מסוג Codex)

- ההגדרות מקבלות נתיב לתוכנית CLI מקומית (ספריות בית בגופנים שאינם ASCII וקידומת ~ נתמכים; ~ מורחב אוטומטית); "זיהוי מודלים" בודק אילו מודלים זמינים ל-CLI.
- האימות בודק רק קיום — ללא הגבלות על מערך התווים.

## מתי השינויים חלים

- שינויים במודל ובנקודת הקצה חלים מיד; שיחה שכבר בעיצומה ממשיכה להשתמש בהגדרה הישנה עד לסבב הבא שלה.
